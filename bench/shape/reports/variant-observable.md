## Decision (hand-written): kept

Target: states-problem, which the baseline failed 0/3 on planted-suggested-fix and real-jsonl-lint. The change rewrites one rule, so an expect line says what a user or caller can observe and never how the code gets there. Why it should help: the baseline's lines that broke the criterion named internals (loadConfig must throw, an exact message), and the old rule allowed them because the request named loadConfig.

Result: states-problem 15/21 to 18/21, catches-traps 19/21 to 20/21, and grounded 21/21 to 20/21. The one grounded miss (planted-bug-regression.3) is a regression proof naming the seed repository's base commit `c82b37b`. That commit was real in the run's worktree, but a seed repository's hash changes with each clone (its committer date is not fixed), so the judge could not see it and called it invented. The stand-in accepts this trade in writing (plan/decisions/2026-11-05-wf-intake-ready.md, "After the build"): the miss reflects the bench's seed hashes, not a worse issue.
