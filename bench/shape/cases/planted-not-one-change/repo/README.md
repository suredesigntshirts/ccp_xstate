# mathlib

Small math helpers used by the invoice service.

## API

### add(a, b)

Returns the sum of `a` and `b`.

```js
const { add } = require('./math.js');
add(2, 3); // 5
```

### multiply(a, b)

Returns the product of `a` and `b`.

```js
multiply(-2, 3); // -6
```
